# Contributing

> 🇧🇷 [Versão em Português](CONTRIBUTING.md)

Thank you for your interest in contributing to **mymangareader**!

## Before you start

Read the [Contributor License Agreement (CLA)](CLA.en.md). When you open a
Pull Request, a bot will ask you to confirm your acceptance — it's a one-time
step per GitHub account.

## Detailed guides

All contribution documentation lives in [`docs/contributing/`](docs/contributing/):

- Development environment setup
- Code standards (Kotlin and TypeScript)
- Branch flow and commit conventions
- How to run tests
- How to add a plugin

## Contribution flow

1. Open an *issue* describing what you want to implement or fix.
2. Wait for discussion before starting — avoids rework.
3. Fork the repo, create a descriptive branch (`feat/123-description` or
   `fix/123-description`) and open a Pull Request against `main`.
4. Fill in the PR template, including the changelog section.
5. All CI checks must pass and a maintainer must approve before merge.

## Reporting bugs

Use the bug *issue template*. Include the app version, APK version, and
minimum steps to reproduce.

## Suggesting features

Use the feature request *issue template*. Explain the problem the feature
solves, not just what you want to implement.
